# C++ OOP Shape Maker

A console-based shape management application developed in C++ as part of an Object-Oriented Programming course.

The project focuses on implementing and applying core OOP principles through a system that creates, manages, and manipulates geometric shapes.

## Project Overview

This project was developed from an existing academic code skeleton. My work involved implementing the required functionality, completing class implementations, resolving compilation issues, and integrating the components into a working application.

The project provided hands-on experience with object-oriented software design and working with an existing C++ codebase.

## Key Concepts

- **Object-Oriented Programming (OOP)** – Organizing functionality into classes and objects.
- **Inheritance** – Building relationships between geometric shape classes.
- **Polymorphism** – Working with different shapes through shared interfaces.
- **Encapsulation** – Separating implementation details from class interfaces.
- **C++ Memory Management** – Managing object lifetimes and resources.
- **Modular Design** – Separating class declarations and implementations into `.h` and `.cpp` files.

## Project Structure

The project includes the following main components:

| Component | Description |
|---|---|
| `Shape` | Base shape abstraction |
| `Circle` | Circle representation |
| `Rectangle` | Rectangle representation |
| `Triangle` | Triangle representation |
| `Polygon` | Polygon representation |
| `Arrow` | Arrow representation |
| `Point` | Coordinate representation |
| `Canvas` | Drawing-related functionality |
| `Menu` | User interaction and application menu |
| `main.cpp` | Application entry point |

## Building the Project

The project uses CMake.

```bash
cmake -S . -B build
cmake --build build
```

Additional graphics dependencies may be required depending on the development environment.
